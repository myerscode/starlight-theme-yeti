## Plugin options

The plugin accepts one option: `overrides`. It controls the 18 component overrides the theme registers.

```js
starlightThemeYeti({
  overrides: {
    // Replace a theme component with your own
    Footer: './src/components/MyFooter.astro',

    // Disable an override and fall back to Starlight's default
    Hero: false,
  },
})
```

Resolution order for each component:

1. `false` — the theme override is skipped; Starlight's built-in component renders
2. A path string — your component renders instead of the theme's
3. Unset — the theme's component renders
4. Anything in Starlight's own `components` config wins over all of the above

See the [Components](/components/) section for what each override does.

## `linkableGroups` sidebar helper

Starlight group headings are plain text by default. `linkableGroups` pre-processes your sidebar so groups with a `slug` get clickable headings:

```js
import { linkableGroups } from '@myerscode/starlight-theme-yeti/sidebar';

sidebar: linkableGroups([
  // Group heading links to /guides/, with hand-picked items
  { label: 'Guides', slug: 'guides', items: [
    { label: 'Getting Started', slug: 'guides/getting-started' },
  ]},

  // Group heading links to /components/, items autogenerated from the directory
  { label: 'Components', slug: 'components', autogenerate: { directory: 'components' } },

  // Plain autogenerate without a slug still works
  { label: 'Reference', autogenerate: { directory: 'reference' } },
])
```

The **Guides** and **Components** groups in this site's sidebar demonstrate both linked variants. Add `collapsed: true` to any group to start it collapsed — **Components** does.

## Sidebar icons

Any sidebar label can start with an `[icon-set:name]` token, rendered by the `SidebarSublist` override via [astro-icon](https://www.astroicon.dev/):

```js
{ label: '[lucide:rocket] Welcome', slug: '' }
```

This site uses [Lucide](https://lucide.dev/) icons (`@iconify-json/lucide`). Install a different Iconify set to use another prefix.

The theme overrides 18 Starlight components. Each can be replaced with your own component or disabled via the [`overrides` setting](/guides/settings/#plugin-options).

| Override | What it does |
|----------|--------------|
| `SkipLink` | Accessible skip-to-content link |
| `PageFrame` | Overall page layout frame |
| `TwoColumnContent` | Content + right sidebar column layout |
| `Header` | Top bar: title, search, social icons, theme toggle |
| `Sidebar` | Navigation sidebar container |
| `SidebarSublist` | Sidebar items — icons, collapsible linked groups |
| `PageSidebar` | Right-hand page sidebar container |
| `Banner` | Per-page announcement banner |
| `ContentPanel` | Content section wrapper |
| `PageTitle` | Page `<h1>` styling |
| `Hero` | Splash page hero section |
| `MarkdownContent` | Prose typography styles |
| `Footer` | Page footer container |
| `LastUpdated` | Last-updated timestamp |
| `EditLink` | "Edit this page" link |
| `Pagination` | Prev/next page cards |
| `ThemeSelect` | Light/dark/system toggle |
| `TableOfContents` | Right-hand table of contents |

The pages in this section group them by where they appear. You reached this page via the collapsed, autogenerated **Components** group in the sidebar — its heading is clickable because the group has a `slug`.

Scroll to the bottom of this page — everything down there is themed:

## Pagination

The prev/next cards with directional arrows, borders, and hover states. Order follows the sidebar; override per page with `prev`/`next` frontmatter.

## LastUpdated

The timestamp under the content, enabled by `lastUpdated: true` in the Starlight config (uses git history at build time).

## EditLink

The "Edit page" link, pointing at this file in the repo via the `editLink.baseUrl` config.

## Footer

The container that lays all of the above out.

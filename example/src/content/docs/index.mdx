## What this site demonstrates

This example is built from the theme source in this repository — every page exercises part of the theme:

- **This page** — `template: splash` with the `Hero` and `CallToAction` overrides
- **[Showcase](/showcase/)** — typography, code, tables, admonitions, and the `Banner` component
- **[Guides](/guides/)** — a linkable group heading with hand-picked items
- **[Components](/components/)** — a collapsed, autogenerated linkable group documenting all 18 overrides
- **The sidebar itself** — `[lucide:*]` icons and clickable group headings via `linkableGroups`
- **[The 404 page](/this-page-does-not-exist)** — provided by the theme automatically, no `404.md` needed
